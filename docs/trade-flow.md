# 거래 흐름 정의

## 전체 상태 전이도

```
[구매자] 상품 게시물에서 예약하기 클릭
              ↓
          RESERVED
              ↓ [판매자] 내 판매 목록 > 예약중 탭 > "예약 확정" 클릭
          TRADING
              ↓ [구매자] 내 구매 목록 > 거래중 탭 > "거래 완료 확인" 클릭
            SOLD
              ↓ [구매자] 내 구매 목록 > 구매완료 탭 > "리뷰 작성" 클릭
          REVIEWED
```

---

## 판매자 흐름 (내 판매 목록)

| 단계 | Trade 상태 | 탭 | 표시 내용 | 가능한 액션 |
|------|-----------|-----|----------|------------|
| 1 | (없음) | 판매중 | 상품 정보 | 수정 / 삭제 |
| 2 | RESERVED | 예약중 | 구매자가 예약 신청함 | **예약 확정** / 예약 거절 |
| 3 | TRADING | 거래중 | 거래 진행중 | "구매자가 완료 처리" 안내 |
| 4 | SOLD | 판매완료 | 거래 완료 | - |

---

## 구매자 흐름 (내 구매 목록)

| 단계 | Trade 상태 | 탭 | 표시 내용 | 가능한 액션 |
|------|-----------|-----|----------|------------|
| 1 | RESERVED | 예약중 | 예약 확정 대기중 | - (판매자 확정 기다리는 중) |
| 2 | TRADING | 거래중 | 거래 진행중 | **거래 완료 확인** |
| 3 | SOLD | 구매완료 | 구매 완료 | **리뷰 작성** |
| 4 | REVIEWED | 리뷰완료 | ✓ 리뷰 작성완료 | - |

---

## 테스트 시나리오

### 전체 흐름 테스트 순서

1. **구매자 계정** 로그인 → 상품 게시물 → 예약하기 클릭
2. **판매자 계정** 로그인 → 내 판매 목록 → 예약중 탭 → 예약 확정 클릭
3. **구매자 계정** 로그인 → 내 구매 목록 → 거래중 탭 → 거래 완료 확인 클릭
4. **구매자 계정** → 내 구매 목록 → 구매완료 탭 → 리뷰 작성 클릭
5. 리뷰 작성 완료 → 리뷰완료 탭으로 이동 확인
