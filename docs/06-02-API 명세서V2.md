# 06. API 명세서 V2

> **버전**: v2 (채팅방 생성 API 추가, 에러코드 통일, retryAfter 정책 및 `ApiResponse` 공통 구조 적용)
> **Base URL**: `https://api.marketplace.com/api/v1`
> **인증**: `Authorization: Bearer {AccessToken}` (🔒 표시 API)

## 📌 공통 응답 구조
모든 API 응답은 `ApiResponse<T>` 구조를 따릅니다. 프론트엔드는 항상 `code` 값을 확인하여 분기 처리합니다.

```json
{
  "code": "SUCCESS",
  "message": "요청이 성공적으로 처리되었습니다.",
  "data": { ... } // API별 반환 데이터 (없을 경우 null 또는 필드 생략)
}
```

에러 발생 시에도 HTTP 상태 코드는 해당 에러에 맞게(400, 401, 404 등) 반환되지만, Body에는 다음과 같이 커스텀 에러 코드가 담깁니다.
```json
{
  "code": "MEMBER_NOT_FOUND",
  "message": "존재하지 않는 회원입니다."
}
```

## 1. 인증 API (Auth)

### `POST` /auth/signup (회원가입) - ❌
*   **Request Body**:
    ```json
    {
      "email": "user@example.com",
      "password": "password123!",
      "nickname": "민준",
      "profileImageUrl": "https://example.com/image.jpg" // 선택
    }
    ```
*   **Response (201 Created)**:
    ```json
    {
      "code": "SUCCESS",
      "message": "요청이 성공적으로 처리되었습니다.",
      "data": {
        "id": 1,
        "email": "user@example.com",
        "nickname": "민준",
        "createdAt": "2025-06-01T10:00:00"
      }
    }
    ```

### `POST` /auth/login (로그인) - ❌
*   **Request Body**:
    ```json
    {
      "email": "user@example.com",
      "password": "password123!"
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "code": "SUCCESS",
      "message": "요청이 성공적으로 처리되었습니다.",
      "data": {
        "accessToken": "eyJhbG...",
        "refreshToken": "eyJhbG...",
        "tokenType": "Bearer",
        "expiresIn": 900
      }
    }
    ```

### `POST` /auth/logout (로그아웃) - 🔒
*   **Request Header**: `Authorization: Bearer {AccessToken}`
*   **Response (200 OK)**:
    ```json
    {
      "code": "SUCCESS",
      "message": "로그아웃 되었습니다."
    }
    ```

### `POST` /auth/refresh (토큰 재발급) - ❌
*   **Request Body**:
    ```json
    {
      "refreshToken": "eyJhbG..."
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "code": "SUCCESS",
      "message": "요청이 성공적으로 처리되었습니다.",
      "data": {
        "accessToken": "eyJhbG...new",
        "refreshToken": "eyJhbG...new",
        "tokenType": "Bearer",
        "expiresIn": 900
      }
    }
    ```

## 2. 회원 API (Member)

    ```json
    {
      "code": "SUCCESS",
      "message": "요청이 성공적으로 처리되었습니다.",
      "data": {
        "id": 1,
        "email": "user@example.com",

        "profileImageUrl": "https://example.com/image.jpg",
        "averageRating": 4.5,
        "reviewCount": 12,
        "createdAt": "2025-06-01T10:00:00"
      }
    }
    ```

### `PATCH` /members/me (내 프로필 수정) - 🔒
*   **Request Body**:
    ```json
    {
      "nickname": "새닉네임",
      "profileImageUrl": "https://example.com/new_image.jpg" // "" 전달시 초기화
    }
    ```
*   **Response (200 OK)**: (수정된 MemberResponse 반환)
    ```json
    {
      "code": "SUCCESS",
      "message": "요청이 성공적으로 처리되었습니다.",
      "data": {
        "id": 1,
        "email": "user@example.com",
        "nickname": "새닉네임",
        "profileImageUrl": "https://example.com/new_image.jpg",
        "averageRating": 4.5,
        "reviewCount": 12,
        "createdAt": "2025-06-01T10:00:00"
      }
    }
    ```

### `PATCH` /members/me/password (비밀번호 변경) - 🔒
*   **Request Body**:
    ```json
    {
      "oldPassword": "password123!",
      "newPassword": "newPassword123!"
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "code": "SUCCESS",
      "message": "비밀번호가 변경되었습니다."
    }
    ```

### `DELETE` /members/me (회원 탈퇴) - 🔒
*   **Response (200 OK)**:
    ```json
    {
      "code": "SUCCESS",
      "message": "회원탈퇴가 완료되었습니다."
    }
    ```

### `GET` /members/{memberId} (타 회원 프로필 조회) - ❌
